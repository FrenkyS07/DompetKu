# 💰 DompetKu - Expense Tracker App

DompetKu adalah aplikasi web sederhana untuk mencatat pemasukan dan pengeluaran harian. Dibuat untuk membantu pengguna melacak arus keuangan mereka dengan tampilan yang bersih, modern, dan mudah digunakan di HP maupun Laptop.

## ✨ Fitur Utama

- **Pencatatan Transaksi:** Input nama, jumlah, kategori, dan jenis transaksi (Pemasukan/Pengeluaran).
- **Kalkulasi Otomatis:** Saldo, Total Pemasukan, dan Total Pengeluaran dihitung secara *real-time*.
- **Riwayat Transaksi:** Menampilkan daftar transaksi dengan indikator warna (Hijau untuk Masuk, Merah untuk Keluar).
- **Hapus Data:** Fitur untuk menghapus transaksi yang salah input.
- **Penyimpanan Lokal:** Data tersimpan di browser (*LocalStorage*), sehingga tidak hilang saat halaman di-refresh.
- **Responsive Design:** Tampilan menyesuaikan layar HP (Mobile First) dan Desktop.

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik.
- **CSS3:** Styling dengan CSS Variables, Flexbox, dan Mobile-First approach.
- **JavaScript (Vanilla):** Manipulasi DOM, Event Handling, dan Logika Matematika.
- **LocalStorage API:** Untuk persistensi data di browser.

## 🚀 Cara Menjalankan

Karena proyek ini menggunakan HTML/CSS/JS murni, kamu tidak perlu menginstal apapun.

1.  Clone repository ini atau download sebagai ZIP.
2.  Buka folder proyek.
3.  Klik 2x pada file `index.html`.
4.  Aplikasi siap digunakan di browser!
